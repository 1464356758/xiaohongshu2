# XHS-BEAUTY-002｜P8快速主链重构完成

## 结论
系统已完成第二阶段重构：在P7产品真源锁基础上，将单条CONTENT默认流程压缩为5阶段快速主链。

## 为什么重构
CONTENT-002证明旧流程存在两个问题：
1. 产品真源没有在生产前锁定，导致Swan Ballet与Snow Ballet串系列；
2. 单条内容需要过多AI角色交接与返修，出现十几到二十多次来回，效率低且越改越乱。

## 新默认流程
1. 热点研究员：候选产品 + 热门贴拆解 + 主选PRODUCT TRUTH包
2. 总监：PRODUCT TRUTH LOCK
3. 内容策划AI：策划 + 正文 + 逐页文案一体化
4. 图片A：完整页组一次生成
5. 图片C：最终像素终审 + 直接修
6. 总监：CONTENT LOCK + 发布包

从用户手动跨AI角度：
热点 → 策划 → A → C → 总监
目标5次。

## 默认跳过
- 文案脚本AI：仅复杂文案/品牌brief时启用
- 图片B：仅A需要大修时启用
- 内容与合规审核：仅高风险触发
- 发布运营：发布前默认跳过，总监直接给发布包

## 常驻并行
- 市场定位研究：每14天/重大方向变化并行，不阻塞单条内容
- 数据分析：发布后24h/72h/7d并行，不阻塞下一篇

## 交接上限
- 普通内容目标：5次
- 高风险内容最多：7次
- 超过7次：自动判定流程异常，停止角色乒乓，由总监决定换题/换素材/结束

## 返修上限
- 策划文案整合：最多1次
- 图片A自修：最多1次
- 图片C终修：最多1次
- 同一个问题不能在多个角色间反复修两次以上
