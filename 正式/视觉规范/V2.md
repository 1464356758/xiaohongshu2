# 视觉规范 V2

## 生效说明
本版本在 V1 基础上增加“服装、动作、构图、场景轮换”硬规则。
人物身份仍由当前有效 PERSONA LOCK 控制，不因换衣服、换动作、换场景而改变人物核心面部结构。

## 总体审美
真人感、生活感、轻高级、适合小红书。
避免“同一张脸反复贴在不同背景上”的拼贴感，也避免连续多条内容使用同一服装、同一动作、同一构图。

## 默认比例与格式
- 3:4竖图
- 推荐1440×1920或更高等比例尺寸
- 最终JPG/PNG

## 默认页数
默认4页：
- P1 封面人物/核心视觉
- P2 问题解释/主题视觉
- P3 核心方法/局部或对比
- P4 总结/互动

必要时可扩展至6页，最高10页。

## 人物一致性
- 必须使用当前有效 PERSONA LOCK
- 脸型、眼距、鼻唇比例、下颌线、肤色、识别痣等核心身份结构保持一致
- 不允许只靠文字重新随机生脸
- 优先基于LOCK真实图片进行编辑/变体
- 换衣服、换动作、换场景不等于换人

## 服装轮换｜新增硬规则
### 跨内容
1. 连续两条CONTENT不得使用同一主服装组合。
2. 最近3条CONTENT中，主服装至少出现2种以上风格。
3. 同一件明显识别度很高的针织衫、吊带、蝴蝶结、外套，不得连续复用。
4. 服装可以服务场景，但不要求每页都换衣服，优先保证同一条内容内部连贯。

### 推荐轮换池
- 白/奶油色针织 + 简洁吊带
- 灰色/燕麦色轻西装
- 白衬衫
- 黑色基础上衣
- 奶咖针织开衫
- 低饱和豆沙粉上衣
- 简洁风衣/薄外套
- 无明显品牌Logo的日常连衣裙

## 动作轮换｜新增硬规则
### 禁止模板化
- “单手托腮 + 正面看镜头”不得成为默认动作
- 同一CONTENT最多1页使用托腮
- 连续两条CONTENT不得以同一主动作作为封面

### 推荐动作池
- 轻扶头发
- 拿小镜子观察妆面
- 侧脸看镜子
- 整理耳边碎发
- 轻拿刷具但不遮脸
- 自然坐姿，双手放桌面/膝上
- 半身站姿，身体微侧
- 走动中的自然抓拍
- 回头看镜头
- 看向窗外或镜外
- 轻触脸颊但不托住整张脸
- 手拿通勤包/咖啡/书等生活道具
- 唇妆/腮红/眼妆局部操作动作

## 构图轮换｜新增硬规则
最近3条CONTENT中至少覆盖3类构图：
- 正面头肩
- 45度头肩
- 半身
- 侧脸
- 镜前
- 坐姿
- 站姿
- 行走抓拍
- 局部妆面细节

同一条4页里，不允许4页全部是同一机位、同一脸部大小、同一手势。

## 场景轮换｜新增硬规则
可轮换：
- 窗边
- 梳妆台
- 客厅/卧室生活角
- 电梯/楼道简洁场景
- 咖啡店靠窗位
- 通勤前玄关
- 室外街边
- 城市夜景
- 商场/写字楼公共区域
- 简洁纯色摄影背景

同一背景不要连续多条复用到让用户产生“复制贴图”感。

## 肢体与真实摄影感｜新增硬规则
每张带上半身/手臂的图必须检查：
- 左右手臂粗细、长度、透视关系是否合理
- 肩膀宽度与手臂连接是否自然
- 手腕、手掌、手指数量与弯曲是否正常
- 手臂不得一粗一细到明显违背透视
- 不得出现悬空手、断臂、穿模、关节反折
- 衣袖厚度变化要符合真实衣料与透视
- 人物边缘光、肤色、噪点、景深必须与背景环境一致
- 禁止人物像“抠图贴上去”：人物与背景需共享同一光向、色温、景深、颗粒和曝光关系

## 光线与色彩
- 柔和自然窗光或真实生活光
- 室外夜景时，人物脸部必须接受真实环境光，不得独立亮成棚拍人像
- 背景霓虹、路灯、窗光和人物肤色要在同一白平衡体系下
- 避免背景冷蓝、人物却过暖过白导致拼贴感
- 保留轻微相机噪点/质感，避免过度磨皮

## 中文排版
- 图片模型主要负责摄影底图、人物与美妆视觉
- 长中文标题、正文、页码优先用确定性文字层排版
- 最终文字逐字与批准文案一致
- 中文优先，禁止随机错误英文
- 图内不额外加技术说明文字

## 产品视觉
如使用具体品牌产品：
- 先核实产品名称/系列
- 不凭空制造错误包装、Logo或不存在的色号
- 有可靠参考图再做具体产品视觉
- 无可靠外观依据时，以妆容/色彩灵感呈现，不伪造实拍产品

## 每条CONTENT必须附带视觉变化记录
图片A交付中必须写：
- 本条主服装
- 本条辅助服装（如有）
- 本条P1主动作
- 本条其他动作
- 本条主场景
- 与上一条CONTENT相比，至少两项已变化：服装 / 动作 / 场景 / 构图

## 禁止
- SVG作为最终发布图
- 明显水印
- 随机错误英文
- 塑料皮
- 不同页人物换脸
- 四页都用同一托腮动作
- 连续多条同一套衣服
- 人物与背景光色完全不一致
- 明显“抠图贴背景”效果
- 左右胳膊尺寸明显失衡
