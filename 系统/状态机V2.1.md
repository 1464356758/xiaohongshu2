# XHS-BEAUTY-002｜状态机 V2.1

## 目标
让每个角色只在正确阶段工作，避免重复执行、越级执行和旧任务复活。

## PERSONA-001
1. READY_FOR_PERSONA_ANCHOR_A
2. PERSONA_A_DONE_WAITING_B
3. PERSONA_B_DONE_WAITING_C
4. PERSONA_C_PASS_WAITING_LOCK
5. PERSONA_LOCKED

说明：
- PERSONA_A允许active_anchor_lock为空。
- B必须看到A实际图。
- C必须看到B最终实际图。
- 只有总监可从C_PASS推进到PERSONA_LOCKED。

## CONTENT-xxx
1. READY_FOR_RESEARCH
2. RESEARCH_DONE
3. COPY_DONE
4. IMAGE_A_DONE
5. IMAGE_B_DONE
6. IMAGE_C_PASS
7. AUDIT_PASS 或 AUDIT_FAIL
8. CONTENT_LOCKED
9. PUBLISH_PACKAGE_READY
10. PUBLISHED_CONFIRMED
11. DATA_24H / DATA_72H / DATA_7D

## 执行规则
- 角色必须检查task_id与input_revision。
- 若当前任务版本高于手里的版本，旧任务立即停止。
- 每个角色只能消费已完成前置阶段的交付。
- B/C阶段以用户上传的实际图片为前置证据。
- FAIL只能回到明确的返修责任角色。
- 同一返修最多2轮；第3次交总监决策。
- 发布运营必须看到CONTENT LOCK。
- 数据分析必须看到真实发布回执。
