# 图片工作流 V2.0

图片是本项目最高优先级。质量优先于数量。默认4张，允许1至10张。

主流程：
内容任务 → 图片生成员A → 图片审核修图员B → 图片终审修图员C → 内容与合规审核。

图片生成员A负责首稿，必须直接生成实际图片；有脸时使用锁定人物；默认封面1张加内页3张；最终使用JPG或PNG。

图片审核修图员B读取A的实际原图，检查人物一致性、五官、手部、发丝、妆容、文字、手机可读性和小红书视觉完成度。可修问题直接修，单页严重问题直接重做该页，整组人物漂移则退回A。

图片终审修图员C读取B最终实际图片，检查第一眼完成度、人物一致、皮肤发丝眼神、文字、页面统一和封面点击理由。可修问题直接修，合格才PASS。

A→B→C之间由用户把实际图片原图上传到下一角色聊天。GitHub记录资产名、页序、版本和审核结论。

命名：
01_cover.jpg
02_page.jpg
03_page.jpg
04_page.jpg
必要时扩展至10_page.jpg。

最终发布图片不能用SVG，也不能只交提示词或空白模板。
