# XHS-BEAUTY-002｜状态机 V2.2

## 总原则
每个任务必须有task_id、input_revision、task_type和pipeline。角色开工前必须确认当前状态允许自己执行；旧版本任务立即停止。

## A. PERSONA人物锚点
READY_FOR_PERSONA_ANCHOR_A
→ PERSONA_A_DONE_WAITING_B
→ PERSONA_B_DONE_WAITING_C
→ PERSONA_C_PASS_WAITING_LOCK
→ PERSONA_LOCKED

PERSONA-001是首次人物任务，允许active_anchor_lock为空。只有总监能创建PERSONA LOCK并更新active_anchor_lock。

## B. 市场与定位
RESEARCH_READY
→ RESEARCHING
→ RESEARCH_DONE_WAITING_DIRECTOR
→ POSITIONING_APPROVED

市场研究不直接修改正式定位。总监验收后才写正式定位新版本。

## C. CONTENT主链
READY_FOR_HOT_RESEARCH
→ HOT_RESEARCH_DONE
→ PLANNING
→ PLAN_DONE
→ SCRIPTING
→ SCRIPT_DONE
→ IMAGE_A
→ IMAGE_A_DONE
→ IMAGE_B
→ IMAGE_B_DONE
→ IMAGE_C
→ IMAGE_C_PASS
→ REVIEWING
→ AUDIT_PASS 或 AUDIT_FAIL
→ CONTENT_LOCKED
→ PUBLISH_PREP
→ PUBLISHED_CONFIRMED
→ OBSERVING
→ ARCHIVED

AUDIT_FAIL必须回到明确责任角色。最多2轮返修，第3次回总监决定换题、换素材、改方案或取消。

## D. 数据与实验
PUBLISHED_CONFIRMED后：
24H_SNAPSHOT
→ 72H_SNAPSHOT
→ 7D_SNAPSHOT
→ EXPERIMENT_REVIEW
→ 总监下一CONTENT任务

没有真实数据可保持OBSERVING或BLOCKED，不得补数。

## E. 增长投放支线
GROWTH_LOCKED
前置：
- 有CONTENT LOCK
- 有自然基线
- 有总监投放任务
- 有用户具体金额授权
- 当前平台投放条件已核实

状态：
GROWTH_READY
→ PLAN_READY
→ USER_APPROVED
→ RUNNING（仅真实开始后）
→ STOPPED/COMPLETED
→ DATA_REVIEW

没有授权不得从PLAN_READY进入RUNNING。

## F. 商务支线
LEAD
→ QUALIFIED
→ QUOTED
→ CONTRACTED
→ PRODUCING
→ ACCEPTED
→ PUBLISHED
→ SETTLED
→ CLOSED
取消：CANCELLED

品牌brief不能跳过CONTENT主链和独立审核。

## G. BLOCKED/PAUSED
任一非终态可进入BLOCKED/PAUSED。
解除后只能回resume_state，不能跳级。

## H. 幂等与冲突
幂等键：task_id + input_revision + role。
重复收到同键先查已有交付。
总监唯一写当前进度。
写前读取当前HEAD；冲突时重新读取，不force。
