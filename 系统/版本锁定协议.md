# 版本锁定协议 V2.0

LOCK用于解决最终发布版本混乱。

触发条件：
1. 热点与文案完成。
2. 图片C通过。
3. 内容与合规审核PASS。
4. 总监最终验收通过。

LOCK文件路径：
批准/CONTENT-xxx/LOCK-V1.json

LOCK必须写入：
task_id、最终标题、正文固定提交、图片C资产版本、每张最终图文件名或可核验资产ID、审核固定提交、总监批准固定提交、允许发布范围、禁止使用的旧版本、created_at。

规则：
- 发布运营只认LOCK。
- A图、B图和历史候选标题不能作为正式发布版本。
- LOCK后任何关键内容变化必须建立新的LOCK版本，旧LOCK保留。
