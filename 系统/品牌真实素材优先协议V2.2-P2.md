# 品牌真实素材优先协议 V2.2-P2

## 目的
品牌单品内容优先建立在真实、可核验的品牌公开素材上，避免AI重画产品造成包装、Logo、色号、材质和结构失真，也避免画面被大段“非真实/视觉示意”免责声明破坏。

## 一、品牌产品本体素材来源优先级
1. 品牌官方网站产品页的真实产品图。
2. 品牌官方旗舰店/官方商城公开产品图。
3. 品牌官方社交账号公开产品图、官方试色图、官方色卡。
4. 品牌官方媒体包、新闻稿、公开宣传资料。
5. 用户自己拍摄的真实产品图。

以上素材必须记录：
- 品牌
- 产品名/系列
- 来源URL
- 来源类型
- 访问日期
- 原图文件名或抓取标识
- 是否为官方产品图/官方试色图/官方色卡

## 二、产品本体禁止AI重画
当内容明确讨论某一真实品牌/真实产品时：
- 不得让生成模型重新“画一个像它的产品”作为最终发布产品图。
- 不得凭文字描述重建包装、Logo、刷头、管身、色号贴纸。
- 不得把AI重建的产品图写成实拍、官方图、到手图或原相机。

允许的非生成式处理：
- 裁切
- 缩放
- 旋转
- 去除纯背景
- 普通抠图
- 亮度/对比度/白平衡调整
- 版式组合
- 加标题、页码、信息卡
- 在不改变产品事实的前提下做轻微色彩统一

不得改变：
- 包装结构
- Logo
- 产品名称
- 规格
- 色号
- 印刷文字
- 产品颜色事实

## 三、试色与色调
### 有官方真实试色
可以使用品牌官方公开试色图，并在后台来源记录中写清来源。
图内不强制写“非本人真实试色”。

### 没有官方真实试色
可以使用：
- 品牌公开色调名称
- 品牌公开色调描述
- 中性色块/色卡作为信息可视化

但不得制作“仿真人嘴唇/手臂试色”来冒充真实产品试色。

## 四、图内免责声明
默认禁止把以下句子作为醒目画面元素反复出现：
- 非真实照片
- 非本人真实试色
- 产品视觉示意
- 妆感适配示意 ≠ 真实上嘴
- AI生成示意

这些说明会显著破坏正常美妆内容观感。

真实性边界优先放在：
1. 后台资产来源记录
2. 正文中的自然来源表达
3. 发布平台的AI内容声明/标识功能（如适用）
4. 审核与LOCK记录

如果某条具体画面在没有说明时会造成实质误认，审核员可以要求最小必要说明，但不能把“免责声明海报化”作为默认模板。

## 五、官方素材与版权/商标边界
“公开可见”不等于“无版权”。
非商业、免费宣传也不自动等于获得授权。

使用官方素材时：
- 优先选择品牌明确提供给媒体/消费者传播使用的素材。
- 保留来源和访问日期。
- 使用量限于介绍、评论、说明该产品所必要的范围。
- 不去除原有版权/来源标识。
- 不把品牌官方图冒充自己拍摄。
- 不暗示品牌已合作、授权、背书。
- 若品牌明确禁止转载或素材授权范围不清，停止直接使用并改为文字/色卡/用户自有真实素材。

## 六、人物页
人物不是产品事实载体。
品牌产品内容不要求每页出脸。

推荐结构：
- P1 官方真实产品图 + 标题
- P2 官方产品图/官方色卡/官方试色图
- P3 可选人物妆感页、局部妆感页或产品使用场景页
- P4 信息总结/选择卡

如果P3使用当前虚拟PERSONA：
- 只表达“妆感方向/搭配思路”
- 不得把人物嘴唇或手臂画面冒充该产品真实试色
- 平台级AI声明按当时实际规则处理，不强制塞入图内大字说明

## 七、AI使用边界
AI可用于：
- 热点研究
- 资料整理
- 版式草稿
- 文案辅助
- 背景氛围方案
- 非产品事实性装饰

AI不得替代真实产品本体素材。

若最终发布图片包含AI生成/合成人物、场景或其他生成合成画面，发布运营仍须根据当时适用法规和平台功能处理AI内容声明/标识；不得通过删除元数据、伪装实拍等方式规避。

## 八、角色执行
热点研究员：
- 热门产品候选必须同时寻找官方产品页与官方真实素材来源。

内容策划：
- 明确每页素材类型：官方产品图/官方试色/官方色卡/人物页/信息卡。

文案：
- 不写“我买了/我用了/我实拍”除非存在真实证据。

图片A：
- 产品本体只能使用官方真实素材或用户真实照片。
- 不生成品牌产品本体。
- 图内不默认加入“非真实/视觉示意”免责声明。

图片B/C：
- 核对产品本体是否来自记录的官方真实素材。
- 检查是否误改包装、Logo、色号、文字。
- 不把“大字免责声明”当默认合规要求。

内容与合规审核：
- 重点检查来源、事实、是否冒充亲测/实拍、是否暗示合作。
- 默认允许干净画面，不强制免责声明海报化。
