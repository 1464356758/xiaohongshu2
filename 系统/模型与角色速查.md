# 模型与角色速查 V2.2

| 编号 | 角色 | 何时启用 |
|---|---|---|
| 01 | 总监 | 每轮决策/验收 |
| 02 | 市场与定位研究员 | 启动、每周、重大转向 |
| 03 | 热点与竞品研究员 | 每条/每批内容 |
| 04 | 内容策划 | 热点确认后 |
| 05 | 文案脚本 | 策划通过后 |
| 06 | 图片生成员A | 文案完成后 |
| 07 | 图片审核修图员B | A图完成后 |
| 08 | 图片终审修图员C | B最终图完成后 |
| 09 | 内容与合规审核 | C最终图完成后 |
| 10 | 发布与社群运营 | CONTENT LOCK后 |
| 11 | 数据分析与实验 | 发布后24h/72h/7d |
| 12 | 增长投放 | 有自然基线+预算授权 |
| 13 | 商务与财务 | 有询盘/报价/合同/回款 |

具体模型以用户界面实际可用为准。图像角色必须使用能查看并编辑图片的能力。
